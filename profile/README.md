# Welcome to Veris

Veris gives developers drop-in SDKs for face capture, liveness detection, document OCR, and face matching - all behind a single API key, with zero biometric images stored. Built to work across regions, devices, and real-world conditions.

## Discover Veris

Veris is identity verification infrastructure for modern mobile apps. It lets developers add face capture, passive and active liveness detection, document scanning, and face comparison to any Android, iOS, Flutter, or React Native app in hours - not weeks. One subscription. One API key. No biometric data stored anywhere.

## Key Features

- **Face Capture**: On-device face capture with a 12-point quality gate, passive liveness (LBP), and active dot-follow challenges. Every result is ECDSA-signed. No image ever leaves the device.
- **Liveness Detection**: Passive liveness and configurable active challenges to detect spoofs and prevent account takeovers in real time.
- **Face Comparison**: Server-side 1:1 face matching powered by ArcFace and RetinaFace - optimised for lower-light conditions and darker skin tones. Images deleted immediately after every request.
- **Document OCR**: On-device extraction from 9 Nigerian ID and utility document types - NIN, passport, driver's licence, voter's card, electricity bill, and more. No upload to any server.
- **Cryptographic audit trail**: Every SDK result is signed with ECDSA and verified server-side - tamper-proof proof for compliance and regulatory reviews.
- **Drop-in SDKs**: Android, iOS, Flutter, and React Native. Single integration. Works across all your apps under one subscription.
