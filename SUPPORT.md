# Support

## Documentation

Start here: **https://verisinfra.com/docs**

The docs cover installation, quick start guides, API reference, and common integration patterns for all platforms.

## GitHub Discussions

For questions about integration, usage, or how something works - open a [GitHub Discussion](https://github.com/orgs/verisinfra/discussions). The community and Veris team both respond there.

## Bug reports

If you found a bug, open an issue in the relevant repository using the bug report template. Include your platform, SDK version, and steps to reproduce.

## Security vulnerabilities

**Do not open a public issue.** See [SECURITY.md](SECURITY.md) for the responsible disclosure process.

## Account and billing

For subscription, billing, or dashboard questions: **hello@verisinfra.com**

## Response times

| Channel | Expected response |
|---------|------------------|
| GitHub Discussions | 1-2 business days |
| GitHub Issues (bugs) | 2-3 business days |
| security@verisinfra.com | 24 hours |
| hello@verisinfra.com | 1-2 business days |
